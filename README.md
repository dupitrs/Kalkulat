# Rast Design

rast studijas dizaina sistēma (v3) kā Claude Code skill.

Tumšā vermiliona sistēma: fons `#0A0A0C`, akcents `#FF4A2E`, Bricolage Grotesque + Inter, punkta ceļojuma signature. Arhetipi: Creator 70 / Ruler 30.

## Struktūra

```
.claude/skills/rast-design-system/
├── SKILL.md    # skill ieejas punkts — kodols, identitāšu izvēle, kvalitātes latiņa
├── tokens.md   # krāsas, tipogrāfija, komponenti, kustība, asset ceļi
├── fonts.md    # fontu saimes, latviešu diakritika, ielādes stratēģija
└── build.md    # būves konvencijas, GitHub Pages deploy, demo lapu process, SEO
```

Skill automātiski ir pieejams jebkurai Claude Code sesijai šajā repo. Avots: `claude skills/rast-design-system` (Google Drive).
